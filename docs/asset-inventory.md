# Asset Inventory

Every image under `RefrenceImages/` (folder name kept as-is — it is the user's
supplied folder), inspected recursively and catalogued for the scrapbook
redesign. Generated by `scripts/contact-sheet.mjs` (contact sheets + JSON) and
verified per-folder by `scripts/verify-sheets.mjs` / `scripts/verify-tiles.mjs`
(first-tile fingerprint match + label-strip read-back), so each sheet provably
shows its own folder.

- Machine-readable data (dimensions, alpha coverage, average colour):
  `docs/asset-inventory.json`
- Visual contact sheets: `docs/contact-sheets/<Folder>.jpg`
- **108 images total across 11 folders.**

Character art is `ComfyUI_`-generated JoJo cutouts: 5 PNGs per character,
~2400–3000 px, most with real transparency (alpha coverage noted) — these are
the centrepieces, not placeholders. No asset is missing or zero-byte.

## Usage rules for the redesign

1. **All visual richness comes from these files** — character cutouts,
   `Elements/` stickers, `Background/` textures and the reference-paper scans.
   No generic CSS illustrations, emoji, stock art, or empty character boxes.
2. Files are copied into `public/assets/` (optimised, lazy-loaded) rather than
   referenced from `RefrenceImages/` at runtime.
3. Reference folders (`RefrenceScrapBooks`, `JojoStyledScrapBookRefrences`,
   `ScrapBookRefrences`, `Background` showcase shots) are **art direction
   only** — not shipped as page content, except as subtle textured layers where
   they read as paper.
4. Per-character palette transitions are keyed to the character folders above.

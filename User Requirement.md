## 4. Reference interpretation boundaries

The supplied images are references, not instructions to reproduce any
one image exactly. They show: - Pastel pink scrapbook collages with
lace, flowers, buttons, bows, kawaii stickers, cameras, music players,
and manga/character images. - JoJo character collages and manga-panel
compositions. - Magazine-like editorial layouts rather than conventional
web page sections. - Romantic photo spreads using polaroids, film
strips, handwritten notes, postcards, and vintage paper. - Blue-toned
Johnny Joestar / Steel Ball Run visual references. - Dense
scrapbook/corkboard arrangements with layered keepsakes and decorative
objects.

## 5. Explicit technology requirement

The requested technology stack is:

-   Next.js
-   Framer Motion
-   HeyGen and/or Remotion **if needed**
-   GSAP
-   Three.js

Interpretation: Next.js, Framer Motion, GSAP, and Three.js are the
requested core stack. HeyGen and Remotion are optional tools to use only
if a specific feature benefits from them.

## 6. Pinterest MCP requirement

The user states that a Pinterest MCP is connected and wants the main
brief to instruct the coding agent to use it. The agent must discover
the actual connected Pinterest MCP tools and schemas in its own
environment, research relevant boards and pins, and document the
references used. It must not invent tool names or claim to have used
Pinterest if the MCP is unavailable.

## 7. Animation requirement

The user explicitly wants a highly animated experience: - Scrapbook
elements should move. - Elements should come together and form scenes. -
Interactions should trigger animations or subsequent scenes. - Examples
include sliding something open, doing an action, and having another
thing play or reveal as a result. - The site should feel interactive,
with things to click on.

## 8. Requirements that remain unspecified

Do not invent these. Use editable placeholders until the creator
supplies them: - Couple's names. - Exact anniversary date. - Actual
relationship timeline and memories. - Personal photographs. - The final
letter/message. - Specific inside jokes or private references. - Which
exact JoJo images/assets the creator has permission to use. - Whether
audio, video, or a generated avatar message is desired.

## 9. Preservation note

This document records what the user asked for and what the supplied
screenshots visibly establish. The PRD and master brief contain
